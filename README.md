YouTube -> MP3 Batch Tagger

Tabs:
    Download    - paste a URL, check metadata, queue songs, download them
    Preferences - MP3 bitrate / sample rate
    Sign In     - AcoustID API key + matching toggle
    Options     - misc app behavior (skip-existing, thumbnails, confirmations...)
    Import      - edit ID3 tags on songs you already downloaded

Workflow (metadata-first):
    1. Paste YouTube URL
    2. Metadata is automatically fetched
    3. Check/correct Artist / Title / Album / Year / Genre
    4. Add to Queue
    5. Paste next URL, repeat
    6. Start Queue
